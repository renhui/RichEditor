# RichNote 重构技术方案

> 版本：v1.0 · 2026-04-27
> 范围：数据层、编辑器、渲染、UI/UX、工程结构、构建、测试

---

## 1. 重构背景与目标

### 1.1 现状问题

当前项目存在几个比较头疼的问题：

- **存储格式乱**：内容以 HTML 片段存储，依赖 `Html.fromHtml` 与正则提取 `<img>`，换台设备就可能出问题
- **编辑器两套并行**：自研 `RichEditor`（多 EditText）和 `RichEditView`（单 EditText + ImageSpan）同时存在，逻辑纠缠不清，光标和删除处理特别脆弱
- **UI 老旧**：ActionBar + LinearLayout 布局，还有自己画的 FAB，手感跟现在的 App 差一截
- **架构耦合**：Activity 直接怼着 SQLite、Glide、文件 IO、业务逻辑，改一处牵一片
- **依赖一堆 jar**：umeng、commons-lang3、photo-view 都是本地 jar，更新维护麻烦

### 1.2 重构目标

1. **Markdown First**：内容存 Markdown 文本，渲染（列表摘要、详情预览、导出）全部走同一套引擎，不再有 HTML 那套
2. **现代 UI**：Material 3 + Jetpack Compose，支持动态主题、深色模式，交互更顺滑
3. **工程现代化**：Kotlin + 模块化 + MVVM/MVI + Hilt + Room + Coroutines/Flow
4. **可扩展**：图片、附件、标签、搜索、导出做成插件式，方便后续加功能
5. **预留演进空间**：云同步、跨端、AI 辅助这些方向先埋好点

### 1.3 本期不做

- 多端云同步、协同编辑
- 富文本二进制格式（Quill Delta、ProseMirror 等）
- 第三方账号体系

## 2. 架构原则

几个基本准则：

- **数据单向流动**：UI → Intent → ViewModel → State → UI，状态都是从 ViewModel 的 StateFlow 来的
- **核心接口化**：渲染、存储、媒体处理各自通过接口隔离，方便以后换实现
- **默认安全**：不持有外部 URI、不往公共目录写东西、不申请多余权限
- **默认离线**：不联网也能用所有功能

## 3. 技术栈

主要用这些：

- **语言**：Kotlin 1.9.x，Java 全撤
- **UI**：Jetpack Compose + Material 3
- **主题**：Material You 动态色（Android 12+），往下走自定义回退色
- **架构**：MVI 或 MVVM，`ViewModel` + `StateFlow` + `Channel`
- **DI**：Hilt
- **异步**：Coroutines + Flow
- **数据库**：Room 2.6+
- **偏好**：DataStore Preferences
- **图片**：Coil 2.x
- **Markdown**：Markwon 4.x + CommonMark
- **导航**：Navigation Compose，单 Activity
- **序列化**：kotlinx.serialization
- **日志**：Timber
- **构建**：AGP 8.x + Gradle 8.x + Version Catalog
- **最低版本**：minSdk 24 / targetSdk 34 / compileSdk 34

## 7. UI / UX 设计

### 7.1 设计语言

- Material 3 风格，动态色优先
- 字体分五级：Display / Headline / Title / Body / Label
- 圆角：默认 12dp，卡片 16dp，按钮 20dp
- 动效用 MotionScheme Standard，列表入场错开，详情页用容器变换
- 深色模式跟随系统，关键颜色对比度 ≥ 4.5
- 可点击元素 ≥ 48dp，支持 TalkBack
- 默认中文，预留英文

### 7.2 主要页面

| 页面 | 功能 | 控件 |
|---|---|---|
| 启动页 | 闪屏 | SplashScreen API |
| 笔记列表 | 首页 | 折叠顶栏 + 搜索 + 瀑布流卡片 + FAB |
| 编辑器 | 创建/编辑 | 三模式 + 底部工具栏 + 键盘适配 |
| 详情页 | 阅读 | 沉浸式 + 目录抽屉 |
| 设置 | 个性化 | 主题、字号、备份 |
| 回收站 | 恢复 | 列表 + 还原/彻底删除 |

### 7.3 笔记列表

- 瀑布流布局，手机单列、平板多列
- 卡片显示：标题（2行）+ 摘要（4行）+ 时间 + 首图缩略图
- 顶栏可折叠，右侧放搜索和排序
- 搜索支持全文匹配（FTS）
- 空态给个插画和引导按钮
- 手势：左滑置顶，右滑删除（带撤销）
- FAB 滚动时收缩

### 7.4 编辑器

**三种模式**：
- 编辑模式：纯文本输入，光标精确
- 预览模式：渲染结果，只读滚动
- 分屏模式：左右对照，滚动联动

**工具栏**分几组：
1. 格式组：H1/H2/H3、加粗、斜体、删除线、代码
2. 块组：引用、代码块、分隔线、列表
3. 插入组：链接、图片、表格、Checkbox
4. 视图组：撤销/重做、模式切换

**输入体验**：
- 自动续写列表符号
- 粘贴 URL 自动转链接格式
- 撤销重做最多 200 步
- 自动保存 500ms 防抖
- 大文档（50KB+）增量渲染
- 分屏滚动同步

**插图流程**：选来源 → 压缩 → 入库 → 插入 Markdown 语法 → 渲染

### 7.5 详情页

- 折叠顶栏，右上角放编辑/分享/导出
- 内容可选中复制
- 长按图片可放大查看
- 顶部阅读进度条，侧边目录抽屉

### 7.6 设置页

- 外观：主题、字号、字体
- 编辑器：自动保存、智能列表、行号
- 数据：导入导出、清理
- 关于：版本、反馈

### 7.7 动效

- 页面过渡用容器变换
- 保存状态用小圆点指示
- 删除带 Snackbar 撤销
- 关键操作有触觉反馈

## 8. 编辑器状态管理

```kotlin
data class EditorUiState(
    val noteId: String,
    val title: String,
    val draftMarkdown: TextFieldValue,
    val mode: EditorMode,
    val saveState: SaveState,
    val outline: List<HeadingItem>,
    val isInsertingImage: Boolean = false,
    val toolbarGroup: ToolbarGroup = ToolbarGroup.Format,
    val undoRedo: UndoRedoState
)

sealed interface EditorIntent {
    data class TextChanged(val value: TextFieldValue) : EditorIntent
    data class TitleChanged(val title: String) : EditorIntent
    data class FormatApplied(val action: EditorAction) : EditorIntent
    data class InsertImage(val source: ImageSource) : EditorIntent
    data class ModeSwitched(val mode: EditorMode) : EditorIntent
    object Undo : EditorIntent
    object Redo : EditorIntent
    object Save : EditorIntent
}

sealed interface EditorEffect {
    data class ShowSnackbar(val msg: String, val undo: (() -> Unit)? = null) : EditorEffect
    data object NavigateBack : EditorEffect
}
```

ViewModel 通过 StateFlow 暴露状态，一次性事件用 Channel。

## 附录 B：编辑器骨架示例

```kotlin
@Composable
fun NoteEditorScreen(
    state: EditorUiState,
    onIntent: (EditorIntent) -> Unit,
) {
    Scaffold(
        topBar = { EditorTopBar(state, onIntent) },
        bottomBar = {
            if (state.mode != EditorMode.Preview) {
                EditorToolbar(state.toolbarGroup, onIntent = onIntent)
            }
        },
        floatingActionButton = {
            if (state.mode == EditorMode.Preview) {
                FloatingActionButton(onClick = { onIntent(EditorIntent.ModeSwitched(EditorMode.Edit)) }) {
                    Icon(Icons.Default.Edit, contentDescription = stringResource(R.string.cd_edit))
                }
            }
        }
    ) { padding ->
        when (state.mode) {
            EditorMode.Edit -> EditorPane(state, onIntent, Modifier.padding(padding))
            EditorMode.Preview -> PreviewPane(state.draftMarkdown.text, Modifier.padding(padding))
            EditorMode.Split -> Row(Modifier.padding(padding)) {
                EditorPane(state, onIntent, Modifier.weight(1f))
                VerticalDivider()
                PreviewPane(state.draftMarkdown.text, Modifier.weight(1f))
            }
        }
    }
}
```
